# Architecture

시스템 구성, 모듈 경계, 데이터 흐름과 운영 절차를 설명한다. 결정의 이유와 대안은 [ADR](../ADR/README.md), 실행할 코드 변경은 [proposals](../proposals/README.md), 검증 결과는 [test-reports](../test-reports/README.md)에 둔다.

현재 파일 목록은 `rg --files --no-ignore docs/architecture`로 확인한다. 새 문서에는 적용 대상과 기준 시점을 적는다.

[2026-02 Vercel runbook](./2026-02-vercel-deployment-runbook.md)은 당시 운영 구성의 역사적 자료다. 현재 설정이나 배포 완료의 증거로 사용하려면 코드와 운영 환경을 다시 확인한다.
